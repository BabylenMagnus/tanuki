---
title: 安装 Tanuki
description: 在 Linux、macOS 和 Windows 上安装、更新和验证 Tanuki。
---

Tanuki 的每个发布版本都会提供 Linux、macOS 和 Windows 的预编译二进制文件
([发布列表](https://github.com/BabylenMagnus/tanuki/releases))。目前还没有 Homebrew、mise 或 Nix 包
— 请使用安装脚本、手动下载,或从源码构建。

## 安装

在 Linux 或 macOS 上运行:

```bash
curl -fsSL https://raw.githubusercontent.com/BabylenMagnus/tanuki/master/website/install.sh | sh
```

在 Windows(PowerShell)上:

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/BabylenMagnus/tanuki/master/website/install.ps1 | iex"
```

安装器会下载适合你平台的发布二进制文件并放到 PATH 上。如果要安装到默认位置以外的地方,设置
`TANUKI_INSTALL_DIR`(在 Windows 上是 `-InstallDir`)。

## 手动下载

也可以直接从 [GitHub releases](https://github.com/BabylenMagnus/tanuki/releases) 下载二进制文件。

选择匹配你系统的产物:

| 系统 | 产物 |
| --- | --- |
| Linux x86_64 | `tanuki-linux-x86_64` |
| Linux aarch64 | `tanuki-linux-aarch64` |
| macOS Intel | `tanuki-macos-x86_64` |
| macOS Apple silicon | `tanuki-macos-aarch64` |
| Windows x86_64 | `tanuki-windows-x86_64.exe` |

在 Linux 或 macOS 上,赋予可执行权限并移动到 PATH 上的某个位置。

```bash
chmod +x tanuki-linux-x86_64
mv tanuki-linux-x86_64 ~/.local/bin/tanuki
```

## 从源码构建

- 与 [`rust-toolchain.toml`](https://github.com/BabylenMagnus/tanuki/blob/master/rust-toolchain.toml) 中固定版本一致的 [Rust 工具链](https://rustup.rs/)
- `git`

```bash
git clone https://github.com/BabylenMagnus/tanuki
cd tanuki
cargo build --release
```

生成的二进制文件是 `target/release/tanuki`(Windows 上是 `.exe`)。将它复制或链接到 PATH 上。

## 验证

启动 Tanuki:

```bash
tanuki
```

如果 shell 找不到 `tanuki`,重启终端,或检查安装目录是否在 PATH 上。

## 更新

Tanuki 会检查新版本并在应用内通知你。也可以手动更新:

```bash
tanuki update
```

`tanuki update` 会下载并安装最新版本。Tanuki 默认使用稳定更新通道;CLI 中也有预览通道
(`tanuki channel set preview`),但目前还没有发布预览构建,所以现在会回退到稳定版清单。

如果某次更新改变了 Tanuki 的客户端/服务器协议,Tanuki 会在安装后询问是否停止旧服务器。要使用新版本,请停止旧服务器。对于默认会话,运行 `tanuki server stop`,再运行 `tanuki`。对于命名会话,运行 `tanuki session stop <name>`,再运行 `tanuki session attach <name>`。

要对受支持的运行中会话启用实验性的实时服务器交接,运行:

```bash
tanuki update --handoff
```

## 开发构建

```bash
just test        # unit tests
just check       # formatting, tests, and maintenance checks
```

## 平台支持

Tanuki 通过同一个发布流水线构建并发布 Linux、macOS 和 Windows 的发布二进制文件 —
Windows 是常规支持的平台,而不是单独的预览通道。
