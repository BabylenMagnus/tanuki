---
title: Tanuki のインストール
description: Linux、macOS、Windows での Tanuki のインストール、アップデート、動作確認。
---

Tanuki はリリースごとに Linux、macOS、Windows 向けのビルド済みバイナリを公開しています
([リリース一覧](https://github.com/BabylenMagnus/tanuki/releases))。Homebrew、mise、Nix 向けのパッケージはまだありません
— インストールスクリプト、手動ダウンロード、またはソースからのビルドを使ってください。

## インストール

Linux または macOS では次を実行します:

```bash
curl -fsSL https://raw.githubusercontent.com/BabylenMagnus/tanuki/master/website/install.sh | sh
```

Windows(PowerShell)では:

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/BabylenMagnus/tanuki/master/website/install.ps1 | iex"
```

インストーラーはプラットフォームに合ったリリースバイナリをダウンロードして PATH 上に配置します。既定と異なる場所にインストールするには
`TANUKI_INSTALL_DIR`(Windows では `-InstallDir`)を設定してください。

## 手動でダウンロード

[GitHub releases](https://github.com/BabylenMagnus/tanuki/releases) からバイナリを直接ダウンロードすることもできます。

システムに合ったアセットを選んでください:

| システム | アセット |
| --- | --- |
| Linux x86_64 | `tanuki-linux-x86_64` |
| Linux aarch64 | `tanuki-linux-aarch64` |
| macOS Intel | `tanuki-macos-x86_64` |
| macOS Apple silicon | `tanuki-macos-aarch64` |
| Windows x86_64 | `tanuki-windows-x86_64.exe` |

Linux または macOS では、実行可能にして PATH 上のどこかに移動します。

```bash
chmod +x tanuki-linux-x86_64
mv tanuki-linux-x86_64 ~/.local/bin/tanuki
```

## ソースからビルド

- [`rust-toolchain.toml`](https://github.com/BabylenMagnus/tanuki/blob/master/rust-toolchain.toml) で固定されたバージョンの [Rust ツールチェーン](https://rustup.rs/)
- `git`

```bash
git clone https://github.com/BabylenMagnus/tanuki
cd tanuki
cargo build --release
```

生成されるバイナリは `target/release/tanuki`(Windows では `.exe`)です。PATH 上にコピーまたはシンボリックリンクしてください。

## 動作確認

Tanuki を起動します:

```bash
tanuki
```

シェルが `tanuki` を見つけられない場合は、ターミナルを再起動するか、インストール先ディレクトリが PATH に含まれているか確認してください。

## アップデート

Tanuki は新しいリリースをチェックし、アプリ内で通知します。手動でアップデートすることもできます:

```bash
tanuki update
```

`tanuki update` は最新リリースをダウンロードしてインストールします。Tanuki は既定で安定版アップデートチャンネルを使います。CLI にはプレビューチャンネルもあります(`tanuki channel set preview`)が、まだプレビュービルドは公開されていないため、現時点では安定版マニフェストにフォールバックします。

アップデートが Tanuki のクライアント/サーバープロトコルを変更する場合、Tanuki はインストール後に古いサーバーを停止するか尋ねます。新しいバージョンを使うには古いサーバーを停止してください。デフォルトセッションでは `tanuki server stop` を実行してから再度 `tanuki` を実行します。名前付きセッションでは `tanuki session stop <name>` を実行してから再度 `tanuki session attach <name>` を実行します。

対応する実行中セッションで実験的なライブサーバーハンドオフにオプトインするには:

```bash
tanuki update --handoff
```

```bash
just test        # unit tests

```

## 対応プラットフォーム

Tanuki は同じリリースパイプラインから Linux、macOS、Windows 向けのリリースバイナリをビルド・公開しています —
Windows は別扱いのプレビュートラックではなく、通常のサポート対象プラットフォームです。
